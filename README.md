# EGH用プロジェクト 「ChemiLens」

![image](https://github.com/HaruyaFujii/ChemiLens/blob/305c04cff9235ec5f62bbb19c16d300a0b29362e/Frame%2013.png)

## About
小中学生に向けた化学をより日常的に感じることができるようにするWebアプリとなっています。
1. 身近なものを撮影
2. 3Dモデルで視覚化
3. ゲーム感覚で学習
を可能とします。
